## 玩法

你是一名学生，要从学校里逃出去。班主任、副班主任和保安会巡逻，
**而且他们会自己上下楼** —— 别以为躲到别的楼层就安全了。

- **WASD / 方向键** 移动（手机用左下**摇杆**拖动）
- **E / 行动键** 交互：拾取、开门、拉闸、商店、制作台
- **V / 跳过键** 在教室或厕所跳过一回合
- 在敌人或监控的视线里待太久会被抓，**被抓会丢失全部道具并送回教室**

### 四档难度

| 难度 | 被发现时间 | 命数 | 其他 |
|---|---|---|---|
| 简单 | 5 秒 | 2 | 不出保安 |
| 普通 | 3 秒 | 2 | 1 名保安 |
| 困难 | 1 秒 | 2 | 2 名保安 |
| 地狱 | **看见就死** | **1** | 大门和侧门封死，只能走路线四或五 |

### 五条逃走路线

1. 被抓住到命数耗尽 → 失败
2. 老师办公室拿工作牌 → 刷开校长办公室拿红钥匙 → 打开大门
3. 小卖部选手电筒以外的黄色钥匙 → 打开一层的侧门
4. 关掉三层 / 四层 / 二层三个电闸 → 打开电子门 → 用锤子砸开后墙
5. 工具房拿锤子 → 砸校长的车得木头 → 小刀 → 主任办公室拿制作图 →
   制作室做黑钥匙 → 开地下室门 → 走到通往校外的楼梯

### 小卖部（全免费，每局只能选一个）

- **隐身针**：监控看不见你，被发现时间从 3 秒延长到 5 秒（持续 30 秒）
- **黄色钥匙**：打开一层侧门
- **可乐**：移动速度 +45%，持续 10 秒
- **小刀**：按 E 捅身边敌人，25% 概率直接解决掉他
- **手电筒**：在任意地下层点亮整层，整局只能用一次（地狱没有）

> 可乐和隐身针都要原地 3 秒才能用上，期间不能移动。
