# 3D 版

## 下载与运行

### 方式一：单文件（推荐，手机/直接双击）

下载 `FPS/index_single.html`，用浏览器打开即可。

Three.js 已内联，**没有任何外部依赖**，`file://` 直接打开也能跑。

线上版：**https://thisisunusername.github.io/EFSHTML/**（部署的是单文件版）

### 方式二：分体版（开发用）

`FPS/index.html` + `FPS/three.module.js` 放同一目录，然后起一个 HTTP 服务：

```bash
cd FPS && python3 -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080/
```

> 分体版用的是 ES module + importmap，**不能用 `file://` 双击打开**（浏览器禁止 file:// 下加载 module，会报「模块没有执行」，页面只有样式、所有按钮点不动）。要直接打开就选单文件版。

## 玩法

你带着搜到的装备进入学校，在有限时间内**搜物资、打敌人，然后跑到撤离点逃出去**。没撤离就算死亡，身上的东西全部丢失。

### 触屏按键自定义
摇杆和 8 个操作键都能拖动摆位。

**入口**：设置 → 触屏页签 → 「进入拖动编辑」。

编辑时控件会加虚线框，按住任意一个拖到顺手的位置，点「完成」退出。
退出后**位置就固定死了**：控件被写成绝对像素定位（`left`/`top`），
不再依赖网格或每帧重算，所以不会出现「松手后自己跑回去」或者
「拖完一走动就漂移」的情况。

- 位置存在 `localStorage`（键 `efs.touchlayout.v1`），下次打开自动还原
- 转屏或窗口尺寸变化超过 8% 时，按新尺寸重新排一次
- 随时可以在同一个页签点「恢复默认布局」回到三列方阵
- 编辑时会暂停游戏逻辑，拖按键不会误触开火 / 跳跃 / 开镜
### 键位导出 / 导入
和存档**完全分开**的一套，纯明文 JSON，不加密，方便直接看、直接改、发给同学。
**入口**：设置 → 触屏页签 → 「导出键位」/「导入键位」/「选文件导入」。
```json
{ "kind": "efs-touchlayout", "v": 1, "screen": "390x844",
  "exportedAt": "2026-11-22T02:10:00.000Z",
  "joyBase": { "x": 105, "y": 105 },
  "items": { "joyZone": {...}, "btnFire": {...}, ... } }
```
- `screen` 是换算依据：换到别的尺寸设备时按 `W/sw`、`H/sh` 等比缩放（限制 0.5~2 倍），再夹回屏内
- 容错：空内容 / 非 JSON / 别人的存档（kind 不符）会明确报错；部分控件、字符串坐标、脏值、越界都能导入
- 脏值只回退它自己那一个控件，不会整块失败；全部读不懂时才提示「已恢复默认布局」
- 导出优先触发下载（`efs-keymap-<时间戳>.json`）；浏览器不给下载时把内容摊进文本框让玩家手动复制
- 导入优先读剪贴板，其次读文本框，也支持直接从下载目录挑文件

### 性能测试（跑分）
**入口**：设置 → 跑分页签 → 「开始性能测试」。

自动沿预设路线走一遍整个场景，全程约 40–50 秒：

```
操场 → 教学楼门前 → 进门 → 1F 走廊 → 1F 楼梯间
     → 2F 走廊 → 2F 教室 → 回 1F → B1 车库 → B2 工具层
     → B3 地下室 → 出楼 → 篮球场 → 体育馆 → 东楼 → 校门终点
```

共 16 段，每段结束时记录一次平均 FPS 和当时的坐标。

屏幕上实时显示：当前段序号 / 进度、滑动窗口 FPS、实时坐标、
draw call 数与三角形数。

结束时给出：

| 项 | 说明 |
|---|---|
| 分数 | 平均 FPS × 100，低于 30 FPS 额外打折 |
| 评级 | S / A / B / C / D 五档 |
| 平均 FPS | 总帧数 ÷ 总秒数，不是各段平均再平均 |
| 最快 / 最慢 | 单帧最高 / 最低瞬时帧率 |
| 分段表 | 16 段各自的 FPS 与坐标 |

测试期间会暂停游戏逻辑（不刷怪、不倒计时、不会被打死），
所以同一台设备每次跑出来的分数是稳定的，可以跨设备直接对比。
结果可以一键复制成纯文本。

### 四档难度

难度不只是改数值，它控制**撤离点数量和单局时长**——难度越高，能跑的出口越少、时间越紧、物资越肥。

| 难度 | 保安 | 老师 | 视野 | 被发现耗时 | 命 | 撤离点 | 单局 |
|---|---|---|---|---|---|---|---|
| 普通 EASY | 0 | 2 | 5.0m | 5.0s | 2 | **3 个** | 10 分钟 |
| 机密 NORMAL | 1 | 3 | 5.6m | 3.0s | 2 | 2 个 | 8 分钟 |
| 绝密 HARD | 2 | 5 | 6.2m | 1.0s | 2 | 1 个 | 7 分钟 |
| 超星 HELL | 3 | 7 | 6.8m | **0s** | **1** | 1 个 | 6 分钟 |

超星难度被看见即死，只有一条命，地下室结局只在这里解锁。

## 技术特点

- **楼层不堆几何**：只渲染当前层，换层时平移玩家高度，五层只占一份场景开销
- **真·空心楼体**：四面 1 米厚外墙 + 顶板 + 4.4 米门洞，内部完全空腔
- **墙按连通方向合并**：一堵 6 米长的墙生成 1 个整体而不是 6 个方块（五层墙段数 27/38/33/33/26）
- **单文件可分发**：`build_single.sh` 把 three.js 内联，零依赖

## 构建

```bash
cd FPS
bash build.sh          # 拼接源码 -> index.html（分体版）
bash build_single.sh   # 内联 three -> index_single.html（单文件版）
```

顺序不能反，`build_single.sh` 读的是 `index.html` 的产物。

源码在 `FPS/full/` 下共 16 个分块，按加载顺序拼接（原因见 `build.sh` 里的注释）。

## 玩法

俯视格子视角。你是一名学生，要从学校里逃出去。班主任和保安会巡逻，**而且他们会自己上下楼** —— 别以为躲到别的楼层就安全了。

- **WASD / 方向键** 移动（手机用左下**摇杆**拖动）
- **E / 行动键** 交互：拾取、开门、拉闸、商店、制作台
- **V / 跳过键** 在教室或厕所跳过一回合
- 在敌人或监控的视线里待太久会被抓，**被抓会丢失全部道具并送回教室**

### 楼层

| 显示名 | 内容 |
|---|---|
| 一层 | 教室、老师办公室、厕所、电闸室、大门 |
| 二层 | 小卖部、校长办公室（需权限）、厕所、侧门 |
| 三层 | 车库、保安室、电子门、校长的车 |
| 四层 | 工具房、主任办公室、制作室、电闸、地下室门 |
| 地下室 | EXIT |

### 四档难度

| 难度 | 被发现时间 | 命数 | 保安数量 |
|---|---|---|---|
| 简单 | 5 秒 | 2 | 0 名 |
| 普通 | 3 秒 | 2 | 1 名 |
| 困难 | 1 秒 | 2 | 2 名 |
| 地狱 | **看见就死** | **1** | 3 名 |

地狱难度下大门和侧门封死，只能走路线四或路线五。

### 五条逃走路线

1. 被抓住到命数耗尽 → 失败
2. 老师办公室拿工作牌 → 刷开校长办公室拿红钥匙 → 打开大门
3. 小卖部选黄色钥匙 → 打开二层的侧门
4. 关掉三层 / 四层 / 二层三个电闸 → 打开三层电子门 → 用锤子砸开后墙
5. 工具房拿锯子 → 锯二层校长的树得木头 → 小卖部选小刀 → 主任办公室拿制作图 → 制作室做黑钥匙 → 开地下室门 → 走到通往校外的楼梯

### 小卖部（全免费，每局只能选一个）

- **隐身针**：监控看不见你，被发现时间从 3 秒延长到 5 秒（持续 30 秒）
- **黄色钥匙**：打开二层侧门
- **可乐**：移动速度 +45%，持续 10 秒
- **小刀**：按 E 掭身边敌人，25% 概率直接解决掉他
- **手电筒**：在任意地下层点亮整层，整局只能用一次（地狱没有）

> 可乐和隐身针都要原地 3 秒才能用上，期间不能移动。

## 隐藏结局

## 外观

主界面右下角有个小按钮，点开就能换皮肤，改完刷新也记得住。

- **风格**：`经典` 是最初那套深蓝配色；`Material` 是 Material Design 3 暗色方案。
- **颜色**：16×16 一共 256 色，选一个当作主色，整套配色会跟着它重新生成。
- 换了风格只管主界面，游戏里的血量条、摇杆和结算页保持原样。
