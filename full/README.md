# full/ — 分块源码

`index.html` 是由这里的 5 个分块**拼接**出来的单文件版本（方便直接双击打开 / 部署）。

源码按顺序拼接：

| 顺序 | 文件 | 内容 |
|---|---|---|
| 1 | `a_head.html` | html 头、全部 CSS、HUD / 摇杆 / 作弊面板 DOM、开始界面、署名 |
| 2 | *(拼接时插入)* | 立即执行函数开头 + use strict |
| 3 | `b_world.js` | 常量、道具表、楼层数据、BFS 寻路、视线判定 |
| 4 | `c_logic.js` | 状态、回合制/经典模式、NPC 跨层巡逻、抓人判定、监控、成就、作弊、排行榜 |
| 5 | `d_actions.js` | 商店、制作、机关交互、结局、输入绑定（键盘/按键/摇杆） |
| 6 | `e_render.js` | 地图缓存、相机、角色/NPC/物件绘制、主循环、启动 |
| 7 | *(拼接时插入)* | 立即执行函数收尾 + script 闭合 + body/html 闭合 |

## 重新拼装

在仓库根目录执行 `bash build.sh`，生成的 `index.html` 就是线上版本。

## 修改建议

- 改玩法数值（速度、发现时间、敌人数量）→ `b_world.js` 里的 `DIFF`
- 改地图（房间、物件、楼梯）→ `b_world.js` 里的 `buildWorld()`
- 改敌人 AI / 抓人规则 → `c_logic.js`
- 改商店、门、机关 → `d_actions.js`
- 改画面、颜色、UI → `a_head.html`（CSS）与 `e_render.js`（绘制）

> 拼接注意：`a_head.html` 必须以 script 开标签结尾并**带换行**，`e_render.js` 必须以立即执行函数收尾并**带换行**，否则单文件会错位（这两个文件末尾都保留了换行）。
